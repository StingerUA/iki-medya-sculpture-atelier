# Демонстрационный AR-ассет

Для проверки механики AR выбран официальный пример `Astronaut` из репозитория Google model-viewer. Документация использует пару `Astronaut.glb` и `Astronaut.usdz` для демонстрации WebXR, Scene Viewer и Quick Look. Сам ассет указан как работа, лицензированная по CC BY 2.0.

Ассет предназначен исключительно для технической проверки AR на карточке FORM / 01. Он не является скульптурой İki Medya и не должен использоваться как фотография, визуализация или коммерческий каталоговый материал.
